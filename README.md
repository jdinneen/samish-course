# Samish Bay, explained

A guided course and data explorer about shellfish-harvest closures in Samish Bay (Skagit County, Washington), 2008–2026.

- **Course:** https://jdinneen.github.io/samish-course/
- **Explorer:** https://jdinneen.github.io/samish-course/explorer.html

**Data** is embedded in the pages. It comes from the Washington State Department of Health's closure calendar and river-sample load calculator, its 2020–2026 closure notices, and USGS stream gauge 12201500 (Samish River near Burlington). Every record and every number stated on the pages is re-checked against those raw files before release.

**The "Ask about the data" chat** calls a small backend service that only answers requests from this site and limits how many questions a visitor, and the whole service, can ask.

This is a historical learning tool.
